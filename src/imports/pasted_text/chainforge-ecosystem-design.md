Design a modern Web3 agency website called ChainForge Ecosystem. The brand centers on a chain-link icon symbolizing "linking" buyers with sellers, and talent with projects. Style: bold, structural, industrial-meets-Web3 — sharp 2–3px corner radii, thin hairline borders (10% black), generous whitespace, uppercase monospace micro-labels, and a confident display headline typeface. Light theme (white/off-white background), NOT a dark crypto-cliché theme.

Brand System

Logo: Orange gradient interlocking hexagonal chain-link mark + wordmark "ChainForge" (Chain in black, Forge in orange) + "ECOSYSTEM" subtext in mono caps with flanking rule lines.

Typography

Display / headings: Big Shoulders Display, weight 800, uppercase, tight line-height (~0.95)
Body: Inter, weights 400–600
Labels / eyebrows / buttons / stats: IBM Plex Mono, uppercase, letter-spacing ~0.1em, small size (~11–12px)

Core components to design as reusable elements

Sticky nav bar: logo left, text links + one solid dark "Get Started" pill button right
Primary button: solid orange, white text, hover → darker orange + lift
Ghost button: 1px border, transparent, hover → dark border
Stat bar: 4-column row with thin dividers, big mono numbers + small caption labels
Connected pillar cards: 3 cards in a row joined by right-arrow dividers (chain-link visual metaphor)
Feature grid card: small icon/number chip, bold caption title, short description
Scrolling pill marquee: rounded pill tags in a horizontally auto-scrolling row, fading edges
Numbered flow step: big mono number, connecting arrow between steps
Vertical progress tracker: circular step dots connected by a vertical line, states = done (filled orange) / active (outlined + glow) / pending (grey)
Form field: label in mono caps above input, soft grey fill, orange focus border
File upload dropzone: dashed border box, changes to solid green border once a file is attached
Footer: 4-column dark footer with logo/blurb, sitemap links, newsletter input, social icons

Notes for the designer / AI tool
Keep corner radii small and consistent (2–4px) — nothing pill-shaped except buttons, badges, and the marquee tags.
Use hairline 1px dividers between grid cards instead of drop shadows — the whole system is flat and structural, not soft/skeuomorphic.
Reserve the orange gradient for accents only (headline highlight words, hover states, active tracker states) — never as a full-bleed background.
Mobile: stack all multi-column grids to single column; collapse nav links behind the CTA button only.
